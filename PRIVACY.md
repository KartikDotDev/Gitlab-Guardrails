# Privacy Policy

GitLab Conflict Guard collects no personal data, merge-request data, browsing history, or usage data.

- No analytics, tracking, telemetry, advertising, or crash reporting is used.
- The extension makes no external network requests.
- It runs locally in Chrome and examines only the pages on GitLab hostnames that the user explicitly authorizes.
- Configuration is stored in Chrome Sync storage: allowed GitLab domains. On managed browsers, an organization can provide the allowed domains through Chrome Enterprise managed storage instead. Chrome may synchronize local configuration under the user's Chrome Sync settings; the extension does not transmit it itself.

For privacy questions, open a GitHub issue in this repository.
