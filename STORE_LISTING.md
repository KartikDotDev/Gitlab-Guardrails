# Chrome Web Store listing copy

## Short description

Blocks GitLab web conflict resolution and guides developers to resolve conflicts locally.

## Long description

GitLab Conflict Guard helps teams avoid accidentally using GitLab's web conflict-resolution workflow. When GitLab displays **Resolve conflicts**, the extension explains that the web flow can update the source branch by creating a merge commit from the target branch.

GitLab Conflict Guard blocks the action and provides your team's local-resolution steps. You can choose the exact GitLab domains it protects.

Everything runs locally in Chrome. The extension collects no data, includes no analytics or telemetry, and makes no external network requests.
