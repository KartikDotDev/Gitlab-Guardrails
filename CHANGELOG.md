# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-03

### Added

- Initial public release of GitLab Conflict Guard.
- Configurable exact GitLab domains and a fixed local-resolution checklist.
- Chrome Enterprise policy support for centrally managed and locked GitLab domains.
- Per-domain optional host permissions and dynamic content-script registration.
- Release documentation, privacy policy, contributor guidance, CI, packaging, icons, and store-asset placeholders.
